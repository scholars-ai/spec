# SPEC-000 · 愿景与范围

- 状态：Draft
- 日期：2026-08-06
- 负责人：Constantine1916

## 1. 一句话愿景

打造一个**自循环的 AI 内容创作 Agent 军团**：自动采集 AI 领域资讯 → 科学评分选出好选题 → 平台专家 Agent 分别产出适配小红书/知乎/公众号的文章 → 文章质量评分把关 → 发布后的真实数据回流 → Agent 从"结果"中学习，选题和写作能力持续进化。

## 2. 双重目标

1. **业务目标**：稳定产出高质量 AI 领域内容，覆盖多个社媒平台，用数据驱动内容策略。
2. **能力目标**：通过生产级项目实践，系统性提升 Agent 开发能力（多 Agent 编排、Evaluation 体系、Agent Memory、人机协作流程）。

第二个目标决定了：**架构上宁可稍微"过度设计"一点，也要把 Agent 工程的关键模式（编排、评估、记忆、可观测）都完整落地一遍**，而不是用一个大 prompt 糊过去。

## 3. 核心闭环（第一阶段五步流程）

```
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
│ ① 选题采集 │──▶│ ② 选题评分 │──▶│ ③ 专家写作 │──▶│ ④ 文章评分 │──▶│ ⑤ 发布+数据 │
└──────────┘   └──────────┘   └──────────┘   └──────────┘   └────┬─────┘
      ▲              ▲                             ▲              │
      │              └───────── 评分权重校准 ◀───────┴───── 数据回流（记忆/反思）
      └──────────────────────── 信源质量学习 ◀────────────────────┘
```

- ① 采集：RSS/信源抓取 AI 资讯、学习资料、大佬分享，形成选题候选池（SPEC-003）
- ② 选题评分：多维 rubric + LLM 评审打分，后续被真实数据校准（SPEC-004）
- ③ 写作：按目标平台分派给专家 Agent（小红书/知乎/公众号），产出 Markdown（SPEC-005）
- ④ 文章评分：平台化 rubric 质量把关，低于阈值打回重写（SPEC-004）
- ⑤ 记忆：发帖数据与文章关联，反思 Agent 提炼"为什么好/为什么差"，写入经验库反哺 ①②③（SPEC-006）

## 4. 第一阶段范围（In Scope）

- 信源：RSS / RSSHub 为主的自动采集 + 手动投喂链接
- 平台：小红书、知乎、微信公众号三个专家 Agent
- 格式：Markdown 输出
- 发布：**人工发布**（系统产出成品文章，人复制发布）
- 数据回流：**人工录入/半自动导入**发帖数据（阅读、点赞、收藏、评论、转发等）
- 人在环（Human-in-the-loop）：选题确认、文章终审两个人工卡点

## 5. 非目标（Out of Scope，第一阶段不做）

- 自动发布到各平台（平台风控复杂，放 M4+）
- 配图/封面生成（架构预留接口，M3+ 实现）
- Markdown 以外的富文本格式（预留渲染层抽象）
- 多租户/对外商业化（单用户系统，但代码按可扩展写）
- 视频/音频内容

## 6. 成功标准

| 阶段 | 标准 |
|---|---|
| M1 | 每天自动产出 ≥10 条已评分的选题候选，评分理由可读、可信 |
| M2 | 选定一个选题后，10 分钟内产出 3 个平台的成品 Markdown 文章，人工修改量 < 30% |
| M3 | 发帖数据与文章 100% 关联；能输出"高/低表现文章归因报告" |
| M4 | 评分体系经过 ≥2 轮数据校准；选题评分与实际表现的相关性可量化且提升 |

## 7. 关键设计原则

1. **Pipeline 显式化**：五步流程是显式的状态机，不是一个黑盒 Agent 的自由发挥。每一步的输入输出都落库、可回放。
2. **Evaluation 是一等公民**：评分不是拍脑袋的 prompt，而是有 rubric、有版本、有校准数据的体系。
3. **人机协作渐进自动化**：先人工卡点，数据证明 Agent 可靠后逐步放开。
4. **一切可观测**：每次 Agent 运行的 prompt、输出、token 消耗、评分全部留痕（Langfuse）。
5. **契约驱动**：服务间通过 `scholar-shared` 的类型契约通信，先定契约再实现。
